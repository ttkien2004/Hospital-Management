# Hospital Management website
** Description **: This is a website which helps users like doctors, nurses, ... to manage every work in hospital.

## 🚀 Main Functions
- Managing patient's data
- Managing medicine's data

## 🛠 Technologies
- Frontend: ReactJS + JavaScript
- Backend: NodeJS + JavaScript
- Database: MySQL

## ⚙️ Setup and Used

### Requirements:
- Node.js >= 20.x
- NPM >= 7.x or Yarn
- MySQL server
1. Clone repository: `git clone https://github.com/ttkien2004/Hospital-Management.git`
2. Set up dependencies:
   - Frontend:
       1. cd frontend
       2. npm i or npm install
       3. npm run dev
       
   - Backend
       1. cd backend
       2. npm i or npm install
       3. npm run start:dev
